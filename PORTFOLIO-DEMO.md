# Portfolio demo

Open `https://mizan-kernel.vercel.app/?demo=1` to enter the dashboard without the client-side login and automatically analyse `public/demo/auctions_full.csv` through the existing Python API.

The demo dataset is a copy of the repository's synthetic `auctions_full.csv`. A bilingual notice identifies it as synthetic and states that government integrations are unavailable. The normal URL retains its existing login flow. Demo visits do not create an administrator session. A reload button allows recovery after a failed data fetch or analysis; manual CSV uploads also remain available.

Deploy this repository before publishing the portfolio's updated demo link. The portfolio entry in `gheid-mycv` describes the current payment-capacity prototype in Arabic and English and links to this demo URL.
